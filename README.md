##  An NIIT group assignment



学校NIIT课程的小组项目，使用Vue3创建的Minecraft Wiki网页前端.



#### 如何使用？

在文件夹空白处单击右键，在git bash中输入

```
git clone https://github.com/ClovertaTheTrilobita/mcwiki-beta.git
```

使用VS Code打开项目，使用

```
 cd .\mcwiki\
```

进入项目文件夹，之后

```
npm install
```

待项目依赖安装完成之后，在文件资源管理器中打开项目文件夹，找到

*./mcwiki/src/server/run server.bat*

双击该批处理文件启动小型后端。

最后在终端输入

```
npm run dev
```

启动项目。
